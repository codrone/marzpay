# Security Policy

## Supported Versions

We actively issue security updates for the following versions of the MarzPay SDK:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of our payment SDK seriously. If you discover a security vulnerability, please follow our responsible disclosure policy:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email your findings privately to `mpalaronald@gmail.com`.
3. Include detailed steps to reproduce the issue, along with any relevant code samples or payload details.

### What to expect:
- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment**: Our engineering team will assess and confirm the issue within 5 business days.
- **Fix & Disclosure**: We will release a patch release (`x.x.+1`) and publish a security advisory on GitHub once resolved.
